# UI Guidelines

## Design Principles
- Use only bright primary colors throughout the application (e.g., blue, red, yellow, green).
- Avoid muted, pastel, or dark color schemes.

## Design System
- Always use Material Design components and patterns for all UI elements.
- Reference the official Material Design catalog for components, layouts, and interactions.

## User Feedback
- Provide big, visible feedback for all user actions (e.g., animations, color changes, snackbars, dialogs).
- Feedback should be immediate and clearly indicate the result of the user's action.

## Technologies
- Use React for all front-end development.
- Use Material-UI (MUI) as the component library for implementing Material Design.

## Accessibility
- Ensure all feedback and UI elements are accessible (e.g., ARIA roles, keyboard navigation).

## Example
- Button click should trigger a large color change or animation, and display a snackbar confirming the action.
